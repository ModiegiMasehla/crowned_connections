# Crowned Connections V1 scope

## Included

- Customer and salon-owner roles in one Flutter application
- Email/password authentication
- JWT authorization
- Salon profiles
- Service catalog and prices
- Hairstyle taxonomy
- Search by hairstyle/service
- Search by distance
- Price/rating filtering
- Google Maps map view
- PostGIS distance filtering/ranking
- Dynamic availability
- Appointment creation
- PostgreSQL double-booking exclusion constraint
- Transactional booking
- Owner accept/decline
- UTC appointment storage
- Africa/Johannesburg display
- POPIA/privacy foundations
- Payment-ready fields
- Docker
- Seed data
- Tests/documentation
